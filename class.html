Border width & radius tokens

  --ra-4: 4px;   /* Small */
  --ra-6: 6px;

  --ra-15: 15px;
  --ra-20: 20px; /* Large */
  --ra-25: 25px;
  --ra-30: 30px;
  --ra-full: 9999px; /* Circular */

* b*-0 provides a no-border option, while b*-1, b*-2, and b*-3 offer a simple scale of border thicknesses for consistent use across.
* Border widths are defined as 1px (thin), 2px (medium), and 3px (thick) tokens to maintain consistent geometry across components.
* Border radius tokens provide a curated range from small to large rounding options, plus a full radius for circular elements.
* border-width: 0 is set by default to ensure that borders only appear when explicitly applied, preventing unintended borders from default styles.
* Border style is solid by default and is not exposed as a utility, as alternate styles are intentionally excluded.
* Border color is set to currentColor, allowing borders to inherit text color directly from the Color System for clear and flexible styling.

Max Width System

Max Width engine via class prefix

:root {
  --mw-base: 100%;
  --mw-add1: 0px;
  --mw-add10: 0px;
}

[class^="mw-"],
[class*=" mw-"] {
  max-width: min(calc(var(--mw-base) + var(--mw-add10) + var(--mw-add1)), 100%);
}

Max-width utilities use intentional base tokens with optional additive modifiers to support precise, responsive layouts. Any mw-* class activates the system automatically, ensuring elements never overflow smaller viewports.

Image System

Layered media engine


.media-layer {
  position: relative;
  overflow: hidden;
}

.img-fill {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.img-pos-right-bottom {
  object-position: right bottom;
}

.media-overlay {
  position: absolute;
  inset: 0;
  background: rgba(0, 0, 0, 0.45);
}

.layer-media { z-index: 1; }
.layer-overlay { z-index: 2; }
.layer-content {
  position: relative;
  z-index: 3;
}

* Images are treated as layout layers rather than fixed boxes, allowing them to behave like background images while remaining semantic <img> elements.
* The image fills its container using object-fit: cover and is clipped by the container using overflow: hidden.
* Layering is standardized to prevent z-index conflicts and ensure predictable stacking behavior.

(() => {
  let activePopup = null;
  let lastFocused = null;

  const focusable =
    'a[href], button, input, textarea, select, not([tabindex="-1"])';

  function openPopup(popup, trigger) {
    if (activePopup) closePopup();

    activePopup = popup;
    lastFocused = trigger;

    popup.classList.add('is-open');
    popup.setAttribute('aria-hidden', 'false');
    document.body.style.overflow = 'hidden';

    (popup.querySelector(focusable) || popup).focus();
  }

  function closePopup() {
    if (!activePopup) return;

    activePopup.classList.remove('is-open');
    activePopup.setAttribute('aria-hidden', 'true');
    document.body.style.overflow = '';

    lastFocused?.focus();
    activePopup = null;
  }

  document.addEventListener('click', e => {
    const open = e.target.closest('[data-popup-target]');
    const close = e.target.closest('[data-popup-close]');
    const overlay = e.target.classList.contains('popup-overlay');

    if (open) {
      e.preventDefault();
      const id = open.dataset.popupTarget;
      const popup = document.querySelector(
        `.popup-overlay[data-popup="${id}"]`
      );
      if (popup) openPopup(popup, open);
    }

    if (close || overlay) {
      closePopup();
    }
  });

  document.addEventListener('keydown', e => {
    if (!activePopup) return;

    if (e.key === 'Escape') {
      closePopup();
    }

    if (e.key === 'Tab') {
      const items = [...activePopup.querySelectorAll(focusable)];
      if (!items.length) return;

      const first = items[0];
      const last = items[items.length - 1];

      if (e.shiftKey && document.activeElement === first) {
        e.preventDefault();
        last.focus();
      } else if (!e.shiftKey && document.activeElement === last) {
        e.preventDefault();
        first.focus();
      }
    }
  });
})();

* Implements a reusable, production‑grade popup system using declarative data attributes.
* Popups are opened explicitly by matching data attributes.
* Only one popup is active at a time to avoid interaction conflicts on documentation pages.
* Includes focus trapping, Escape key dismissal, focus return, and background scroll locking.
* Styles are minimal and intended for documentation clarity only.
* Recommended when a single popup system exists per page.
